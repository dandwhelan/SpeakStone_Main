Feature study · SpeakStone 3.x

The NPC speech frame

A small, Legion-style speaking frame that takes over when the quest window closes. It shows who is talking, lets you pause or stop the voice, and scrolls the text in step with the audio. Below: three interactive mockups, what the WoW API allows, and a build plan.

Layouts

What each one is for

A · Cinematic bar

Closest to the Legion and Dragonflight cinematic text boxes in the request. Wide, low, semi-transparent; three lines visible, auto-scrolling. Best default.

B · Talking head

Matches Blizzard's own TalkingHeadFrame, so it feels native and players already know where to look. Can share its anchor so the two never overlap.

C · Subtitles

No chrome, just the line being spoken. Controls appear on mouse-over or while paused. For players running Immersion or DialogueUI who want minimal UI.

Feasibility

What WoW lets an addon do

Most of this is easy. The one hard limit is pause: PlaySoundFile returns a handle you can only stop. There is no pause, no seek and no way to ask where playback is.

Pause options

ship first

Stop, resume from the top

Pause calls StopSound and keeps the frame open. Resume replays the whole clip and the text rewinds with it. Works with today's packs. Fine for short gossip, annoying near the end of a long quest.

recommended

Sentence-split clips

The pack ships each line as numbered parts (123_description_01.ogg, _02…). The addon chains them with the existing end timer. Pause stops the current part; resume replays that part. Losing a few seconds at most, and timestamps come for free.

avoid

Mute the channel

Set the Dialog volume to 0 while the clip keeps running. It is not a pause: the audio carries on silently and is gone when you unmute. It also fights with the existing "silence Blizzard's voice" setting.

Read-along

Getting the text in step with the voice

  1. Estimated (no new data). Split the text into sentences and give each a share of the clip length by character count, with a small weight for punctuation pauses. TTS speaks at an even rate, so this lands within a second or so on most lines. Works today for every clip.
  2. Sentence timestamps (small data). Generate during pack build. Either take word timings straight from the TTS engine (most engines can return them) or run forced alignment over the existing audio with WhisperX, aeneas or Montreal Forced Aligner. Store sentence start times in a per-pack Lua table. Roughly 30–40 bytes a clip.
  3. Word timestamps (karaoke). Same pipeline, finer grain. Several times larger. Nice to have, not needed for scrolling.
-- SpeakStone_TWW_EN/Timings.lua  (generated, sentence start times in seconds)
SpeakStone_RegisterTimings("SpeakStone_TWW_EN", {
  ["78421_description"] = { 0, 3.42, 7.9, 12.65, 17.1 },
  ["78421_completion"]  = { 0, 2.8, 6.05 },
  ["gossip_214523_1"]   = { 0, 4.1 },
})

Matching: the addon splits the live text with the same sentence rules the build tool used. If the count differs (a player name token, a changed line), it falls back to the estimate for that clip.

Build plan

How it would land in the code

  1. Capture on play. In PlayQuestAudio, PlayGossipAudio and PlayItemAudioDirect, add text, npcID and title to soundData. In DoPlaySound, record startedAt = GetTime().
  2. Playback events. Fire a small internal callback (OnClipStarted, OnClipFinished, OnClipStopped) from DoPlaySound, FinishPlayback and StopCurrentSound. The frame listens; nothing else changes.
  3. New file SpeechFrame.lua. One frame, three skins (A/B/C). OnUpdate throttled to 10 Hz works out the current sentence and scrolls. Draggable, scale slider, remembers position.
  4. When it shows. Setting: Off / When the dialogue window closes (default) / Always. Hidden while Blizzard's talking head is up, which the yield logic already detects.
  5. Controls. Pause/Resume, Stop, Replay, Close. Books get Next page. Add a "Pause narration" keybind next to the existing one in Bindings.xml.
  6. Sync data later. Ship estimated sync first. Add SpeakStone_RegisterTimings and a tools/build_timings.py step to the pack pipeline when packs are next rebuilt.
  7. Sentence-split audio. Optional phase two: unlocks real pause/resume. Needs a pack format change, so version it and keep single-file clips working.
